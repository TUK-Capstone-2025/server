# 🚴 안전중심 자전거 운행보조 시스템

### 📌 프로젝트 소개
아두이노 센서, 안드로이드 앱, 웹을 연동하여 자전거 이용자의 안전한 주행을 지원하는 시스템입니다.

### 🛠 기술 스택
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **API:** REST API
- **Build Tool:** Gradle

### ✨ 주요 기능
- 회원가입 및 로그인
- 팀 생성 및 팀원 관리
- 주행 기록 저장 및 조회
- GPS 좌표 기반 주행 경로 관리
- 웹 및 안드로이드 앱과의 API 연동

### 👩‍💻 담당 역할
**Backend 개발 전담**
- Spring Boot 기반 서버 개발
- 데이터베이스 구성 및 REST API 구현
- API 명세서 작성 및 공유
- 웹·안드로이드 앱 개발 담당자와 협업
